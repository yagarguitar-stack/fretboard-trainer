スケールモード
  • ルート音＋スケール種類を選ぶと全フレットに度数カラーで表示
  • 指板の音をクリックして単音確認できる
コードトーンモード
  • ルート音＋コードタイプを選ぶと全フレットに度数カラーで表示
  • クリックで音を個別に解除 / 再クリックで再選択
  • 弦番号クリックでその弦をミュート（×表示）/ 再クリックで解除
ボイシング作成モード
  • コードトーンのポジションがゴーストで表示される
  • 各弦1ポジションをクリックして自分のボイシングを入力
  • 同弦の別ポジションをクリックすると入れ替わる
  • 弦番号クリックでミュート、ミュート弦は入力不可
  • 「鳴らす」ボタンでアルペジオまたは全音同時再生
  • コード変更時はボイシング・ミュートがリセットされる
全音名モード
  • 全フレットの音名を色付きドットで一覧表示
  • クリックで単音確認できる

基本の流れ
  1. チューニングを選択
  2. 練習モードを選ぶ（クロマチック／スケール）
  3. クロマチック：開始フレットと音符を決めてスタート
  4. スケール：ルート音とスケール種類、ポジション範囲（0〜12F）、方向・リピートを決めてスタート
指板の操作
  • クリックで音を個別解除 / 再クリックで再選択
  • クリックした音を単音再生（音トグルで無効化可）
  • 全弦解除 / 全弦選択ボタンで一括切替
メトロノーム
  • BPM・拍子・音符・アクセントを設定してスタート
  • カウントイン1小節後に自動スタート
  • スタート位置スライダーで任意の音から開始できる
  • ドラムは「🥁 ドラム」ボタンでON／OFF。再生中にONにしても次の拍から拍と小節に合わせて入る
  • ドラムのマス目は常に表示。タップして自分のパターンを作れる
  • 往復モード：上昇→下降→スタート音まで上昇を繰り返す
表示切替
  • 表記：♯ / ♭ の切替
  • 音名：English / イタリア語（カタカナ）の切替
  • 音：あり / なし で再生を無効化
  • 現在音カード：English / イタリア語 / 両方を切替
